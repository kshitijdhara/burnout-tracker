# Code of conduct

BurntOut adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct, for everyone taking part in this project: issues,
pull requests, discussions and any other project space.

In short: be welcoming and kind, assume good intent, give and take
feedback gracefully, and focus on what's best for the people who use
BurntOut. Harassment, personal attacks and sharing someone's private
information aren't tolerated.

This project is about burnout, so please also be gentle with each other.
Nobody owes the project a fast reply.

## Reporting

If someone's behaviour makes you uncomfortable, report it privately to the
maintainer, [@kshitijdhara](https://github.com/kshitijdhara), through the
email address on their GitHub profile. Reports are handled confidentially,
and the maintainer will respond as the Contributor Covenant's enforcement
guidelines describe.
